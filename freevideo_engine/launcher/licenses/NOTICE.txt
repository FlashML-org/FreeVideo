FreeVideo desktop components

The desktop application uses unmodified Qt, PySide6 Essentials and Shiboken6
6.11.2 from the Qt Project. The applicable open source license texts are
included in this directory. The Qt libraries are dynamically linked.

Qt and third-party component notices:
https://doc.qt.io/qt-6/licenses-used-in-qt.html

Corresponding component source:
https://code.qt.io/cgit/qt/qtbase.git/tree/?h=v6.11.2
https://code.qt.io/cgit/qt/qtdeclarative.git/tree/?h=v6.11.2
https://code.qt.io/cgit/qt/qtshadertools.git/tree/?h=v6.11.2
https://code.qt.io/cgit/pyside/pyside-setup.git/tree/?h=v6.11.2

FreeVideo-Pascal source and build instructions:
https://github.com/SrCodeGorilla/FreeVideo-Pascal
Install constraints/windows-launcher.txt and run scripts/build_windows.py
with --onefolder to build a distribution with replaceable Qt libraries.
FreeVideo does not restrict modification of these libraries or reverse
engineering for debugging modifications to them.
