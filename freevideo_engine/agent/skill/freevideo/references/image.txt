# Pictures

- Quick change (crop, rotate, flip, pad, adjust, text, shapes, overlays, remove burned-in captions): `freevideo_edit_image`. The result is a new input file usable as a first frame or reference.
- Layered edits like the image editor page: `freevideo_image_create` opens a session, `freevideo_image_read` gives the document and revision, `freevideo_image_operations` applies 1 to 64 edits atomically, `freevideo_image_render` makes a PNG input file. Read the revision and layer ids before each edit; on `image_changed` read again.
- A new picture from a prompt, or combining input pictures, or a first frame with cast members: `freevideo_generate_image`.
  The picture model is the installed one: MiniMax H3 Image or Qwen-Image 2.1. With both installed it is the one chosen on the picture page; `model` names one. With `aspect`, H3 Image makes about 4 MP (`tier` high: about 16 MP) and Qwen about 1 MP; `width` and `height` are used as given, except that H3 Image makes a smaller shape at the same ratio in 4 MP and does not scale it back; Qwen takes at most 2048. The result states the real width and height; use those when the picture becomes a first frame or a reference, and make it smaller with `freevideo_edit_image` or the picture editor if needed. Input pictures, `seed`, cast members and `scene_image` are given the same way for both. Cast members placed with `people` use Qwen-Image 2.1 when it is installed. The result is an input file; use it as a first frame of a video job.
- Check the result with `freevideo_look` before using it.
