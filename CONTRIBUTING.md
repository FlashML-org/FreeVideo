# Contributing / 参与贡献

Bug reports and suggestions are welcome, in English or Chinese.

- **Feedback:** open an [issue](https://github.com/FlashML-org/FreeVideo/issues) with a short description and the FreeVideo version. A local diagnostic report helps. Small fixes, refactors and cleanups are reported this way too, not as pull requests.
- **Pull requests:** we accept pull requests that add a substantial new capability, such as support for new hardware or a new platform. Open an issue first to agree on the scope, then explain the change and how you checked it. For performance changes, include before/after measurements with the same settings.

If you used AI tools, say so in the pull request. Understand and run every line you submit.

Contact: [Discord](https://discord.gg/MsA277cJzZ) · [QQ Group](https://freevideo-community.pages.dev/qq) · [WeChat Group](https://freevideo-community.pages.dev/wechat).

欢迎用中文或英文反馈问题、提出建议。

- **反馈问题：**在 [Issues](https://github.com/FlashML-org/FreeVideo/issues) 简单说明问题和 FreeVideo 版本。如方便，可附本地诊断报告。小的修复、重构和清理也请这样反馈，不要提交 PR。
- **提交改动：**我们只接受带来实质性新能力的 PR，例如对新硬件或新平台的支持。请先开 issue 讨论清楚范围，再提交改动，并说明改了什么、如何验证。性能改动请附相同配置下的前后对比。

如果使用了 AI 工具，请在 PR 中说明；提交的每一行都要自己理解、实际运行过。

联系：[Discord](https://discord.gg/MsA277cJzZ) · [QQ 群](https://freevideo-community.pages.dev/qq) · [微信群](https://freevideo-community.pages.dev/wechat)。
